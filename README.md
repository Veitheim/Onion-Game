# Onion-Game

Roblox

A Roblox game. The scripts in this repository are published with [Bloxcode](https://bloxcode-docs.seidl.workers.dev), the external code editor for Roblox Studio.

## Layout

The `src` folder mirrors the game's services. `.server.luau` files are Scripts, `.client.luau` files are LocalScripts and `.luau` files are ModuleScripts. The layout works with [Rojo](https://rojo.space) too (`default.project.json`).
